Users and goals

  • Grown-up (parent, teacher, therapist): picks the activity, runs rounds, reads progress that means something for the chosen game.
  • Kid: never touches the tabs; sees and hears only the stage.
  • Speech area (teammates): needs a #talk element to mount Talk with Bean into.

Screens and states

  • Move tab (default, first visit): today's page minus nothing; Word tries shows only for Say It to Sneak (already on talk-with-bean).
  • Talk tab: stage, Robot card, and the empty #talk panel. Start is hidden until Talk with Bean exists, so nothing is shown that does not work.
  • Mid-round tab press: same rule as Restart. The first press warns, a second press within 4 s stops the round and switches.
  • Phone remote: shows the same tab as the laptop; pressing a tab on the phone switches the laptop.
  • Loading, empty and error: none new. Storage refused (private browsing) opens on Move every time.

Design tokens

No new tokens. Uses --accent #ffc83d for the chosen tab, --surface #fff for the other, --line #2b2140 for outline and shadow, --radius-btn 14px, --bw 2px, Fredoka 700 for the labels, and --focus #1a3fd6 for the focus ring. Contrast: #2b2140 on #ffc83d is 9.7:1, and on #fff it is 15.1:1.

Not in this change

  • Talk with Bean itself, its settings and progress, and POST /talk: the speech area builds them.
  • Any animation on the tab switch.

Open questions

  1. Robot card position. Today the order is Progress, Robot, Settings. A tab panel is one block, so Robot moves below Settings, under the panel (shown above). The other choice is Robot first, above the panel.
  2. Mid-round tab press. The proposal reuses the Restart rule (press twice within 4 s). The other choice: switch at once and stop the round, as the request's wording allows.
  3. Start on the Talk tab. The proposal hides it until Talk with Bean exists. The speech area then shows it.
